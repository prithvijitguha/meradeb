# Meradeb

Meradeb(MAY-rah or meh-rah) it translated to "MY" and is taken from the Hindi word 'mera'. Its meant to signify a customization of Debian for
myself and through my vision.

This repo was forked from the Omakub repo, I discovered Omarchy and Omakub before I discovered who DHH was.

Installations to run

```bash
curl -fsSL https://raw.githubusercontent.com/prithvijitguha/meradeb/main/boot.sh | bash
```
