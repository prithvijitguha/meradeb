# **Install Guide**

This page covers the installation guidelines for Meradeb on an existing
Debian 13

Command

``` bash
curl -fsSL https://raw.githubusercontent.com/prithvijitguha/meradeb/main/boot.sh | bash
```

## Options for install

-   Default: This is the default installation which installs all
    components. See below component based installation with Advanced
-   Advanced(Install Individual Components):
    -   GNOME Extensions and Settings(All gnome shell extensions,
        settings and hotkeys)
    -   Terminal Packages (All terminal based packages sourced from
        Debian repo, flatpak and some source installations
    -   Desktop Packages (All desktop based packages)
    -   Applications (All applications with icons to be installed at
        Dock and the meradeb script)
